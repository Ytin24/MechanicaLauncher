# Обнаружение и очистка TLauncher

Проверка при запуске закрывает основной интерфейс до получения результата. Файлы, собственные папки и подтверждённые записи Windows для TLauncher блокируют навигацию, игру и импорт. Отмена очистки возвращает к блокировке. После удаления выполняется повторная проверка; отложенные ссылки и импорт продолжаются только после её успешного завершения. Сканирование ничего не удаляет.

TLegacy и оставшиеся игровые данные не блокируют лаунчер. Ошибка проверки и недоступные ранее подтверждённые файлы сохраняют блокировку с возможностью повторить проверку. Подробности проверки и пропуски доступны в отчёте.

Проверяются известные папки AppData/Program Files, путь игры из настроек TLauncher, InstallLocation подтверждённых записей HKCU/HKLM, ранее найденные корни и выбранные пользователем папки. Новый выбранный путь дополняет предыдущие. Обход ограничен глубиной и количеством объектов; весь диск не сканируется.

## Границы очистки

- Имя `TLauncher.exe` само по себе не разрешает удаление: проверяются метаданные продукта/издателя или адрес сервиса. Для JAR проверяются классы приложения и модпаков; для известных файлов настроек — адрес сервиса TLauncher.
- Признаки TLegacy / TL Legacy / Legacy Launcher, его пространства имён и бренды имеют приоритет над положительными признаками TLauncher. Наличие Legacy не скрывает отдельную установку TLauncher.
- Собственная папка `.tlauncher` / `TLauncher` с подтверждённой принадлежностью удаляется вместе с вложенными файлами, кэшем, журналами, библиотеками и её Java. Одного имени папки недостаточно. В диалоге такая установка показана одной папкой.
- Миры, моды, версии игры, ресурсы, конфигурации и скриншоты защищены. Общая `.minecraft` целиком не удаляется. Legacy внутри папки отменяет удаление всего корня: остаётся только очистка отдельных подтверждённых файлов TLauncher. Общие Java и библиотеки не затрагиваются.
- Символические ссылки, junction и пути через них пропускаются. Корни дисков и сетевые папки не принимаются как выбранная папка лаунчера.
- Перед удалением папки проверяются повторно. Подтверждение целой папки включает её текущее содержимое, в том числе новый кэш. Для отдельно показанных файлов и ярлыков обязательны прежние размер и SHA-256. Появившийся Legacy отменяет удаление всего корня.
- Все выбранные файлы сначала копируются с проверкой SHA-256; ошибка копирования останавливает удаление. Файлы удаляются по одному после повторной проверки, папки — только пустыми, без рекурсивного удаления.
- Ярлыки рабочего стола, меню «Пуск» и автозагрузки удаляются только при ссылке на подтверждённый EXE/JAR TLauncher. Для Java проверяются `-jar` или точный главный класс и classpath; общие команды Java не подходят.
- В HKCU/HKLM удаляются подтверждённые ключи Uninstall, собственные настройки TLauncher и отдельные значения Run/RunOnce. Содержимое с признаками Legacy исключено. Перед удалением сохраняется снимок ключа с типами значений; изменившиеся записи пропускаются.
- Завершаются только подтверждённые процессы TLauncher с совпадающими PID, временем запуска, путём EXE и неизменённым файлом приложения. Дочерние игровые процессы не завершаются. Заблокированные и недоступные файлы остаются в отчёте.
- Если удаление выбранных файлов или ключей требует прав администратора, после подтверждения запускается отдельный процесс очистки через запрос Windows UAC. Основное окно и игра остаются с обычными правами. Отмена UAC оставляет установку на месте.
- Отдельный процесс проверяет SHA-256 задания, заново определяет принадлежность файлов и ключей и ограничивает очистку согласованным списком. Разрядность реестра сохраняется; ключи HKCU привязаны к исходной учётной записи. Изменившиеся записи и новые установки не добавляются в список удаления.
- Чужой деинсталлятор не запускается; общая Java, Prefetch, службы и задачи по совпадению имени не удаляются.

Копии: `<данные лаунчера>/backups/tlauncher/<дата-id>/`. `manifest.json` связывает исходные пути, атрибуты, файлы `0001.bin` и их хеши; содержит список папок. `registry.json` хранит hive, разрядность, ключи, значения и типы записей Windows. `result.json` содержит удалённые и пропущенные пути. Копии не запускаются и не восстанавливаются автоматически.

Автоматическая миграция миров и подбор замены модов не выполняются: исходные игровые данные сохраняются без изменений.

## Источники для различения Legacy

В [официальной документации Legacy Launcher](https://docs.llaun.ch/en/launcher/arguments) используются параметры с префиксом `tlauncher.bootstrap` и бренд `legacy`, поэтому общего совпадения `tlauncher` недостаточно. [Исходники Legacy](https://github.com/LegacyLauncher/archive) также содержат старые имена конфигураций `tlauncher.cfg` и `tlauncher.properties`; они не входят в список очистки. [Инструкция TLauncher](https://tlauncher.org/en/uninstall-tl.html) описывает собственные папки и штатное удаление; общая `.minecraft` целиком здесь не удаляется.

Запрос повышения прав следует [рекомендации Microsoft о выделенном процессе](https://learn.microsoft.com/en-us/windows/win32/secbp/running-with-administrator-privileges).

Проверки используют временные папки, ярлыки и отдельную ветку `HKCU\Software\MechanicaLauncher.Tests\<id>`. Проверяются удаление собственного корня, сохранение Legacy и игровых данных, замена файлов и записей после просмотра, новый кэш, отмена, заблокированные файлы, NTFS junction и передача задания отдельному процессу. Реальные установки не удаляются в тестах; интерактивное подтверждение UAC требует пользователя.
