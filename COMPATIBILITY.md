Настоящее portable-окно проверено на запуск, single-instance forwarding и штатное закрытие. ## Воспроизведение

Команда скачивает файлы и открывает игровые окна. Требуются Windows x64, доступ в интернет, свободное место и возможность работы OpenGL.

```powershell
.\scripts\Test-Compatibility.ps1 -DownloadAndRun
```

Одна пара:

```powershell
dotnet run --project tests/MechanicaLauncher.Core.Tests -c Release -- --smoke out/integration 1.21.1 NeoForge 21.1.250
```

Обычный запуск проекта проверок без `--smoke` не скачивает игры и не открывает окна.

- Разрешён однократный переход с точным содержимым подготовленного HTML. Посторонние `data:`-переходы остаются заблокированы. Панель ждёт готовности WebView2 и документа; ошибка или тайм-аут показывают сообщение и повтор, детали записываются в `logs/catalog.log`.
- Проверка компонента WebView2 подтвердила текст и вычисленный цвет фона для обеих тем, UTF-8 и блокировку постороннего документа. Использовался отдельный профиль, без управления пользовательским окном и без авторизации. Лог: `out/description-fixed.log`.
- 62 локальные проверки и Debug x64 проходят. Логи: `out/description-tests.log`, `out/description-build.log`. Полная визуальная проверка WinUI-страницы остаётся недоступна из-за native computer-use.
