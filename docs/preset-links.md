# Ссылки на сборки

Автор выкладывает сборку один раз и ставит под видео одну ссылку. Зритель нажимает на неё, браузер открывает Mechanica Launcher, лаунчер показывает название и источник сборки, а после подтверждения скачивает её как отдельную сборку и выбирает её на главной. Остаётся нажать «Играть».

## Как сделать ссылку

1. В лаунчере открой меню сборки → «Экспорт .mrpack». В файл попадут моды, конфиги, ресурспаки, шейдеры и миры из `saves`. Лишние миры лучше удалить перед экспортом.
2. Выложи файл:
   - на [Modrinth](https://modrinth.com) как модпак — тогда моды скачиваются с Modrinth, файл маленький, обновления выходят новыми версиями;
   - или на любой хостинг, который отдаёт файл по прямой HTTPS-ссылке (GitHub Releases, свой сервер, S3 и т. п.).
3. В лаунчере: меню сборки → «Ссылка для зрителей…». Вставь страницу модпака на Modrinth или прямую ссылку на `.mrpack`, при желании укажи адрес своего сервера. Готовая ссылка скопируется в буфер обмена.

То же самое делает страница <https://ytin24.github.io/MechanicaLauncher/p/>: вставь адрес и скопируй результат.

## Форматы ссылки

Все три варианта ведут к одной и той же сборке.

| Где использовать | Ссылка |
| --- | --- |
| Описание YouTube, Telegram, Discord | `https://ytin24.github.io/MechanicaLauncher/p/?modrinth=<slug>` |
| Кнопка на своём сайте | `mechanica://pack?modrinth=<slug>` |
| Вставить в лаунчер вручную | любая из ссылок выше, страница `modrinth.com/modpack/<slug>` или прямая ссылка на `.mrpack` |

YouTube не делает кликабельными ссылки вида `mechanica://`, поэтому под видео нужна HTTPS-ссылка. Страница по ней открывает лаунчер, а если он не установлен, предлагает его скачать.

Параметры:

| Параметр | Значение |
| --- | --- |
| `modrinth` | slug или ID модпака на Modrinth |
| `version` | ID или номер версии на Modrinth. Без него ставится последний релиз |
| `url` | прямая HTTPS-ссылка на `.mrpack` (вместо `modrinth`) |
| `sha512` | SHA-512 файла по `url`. Если указан, лаунчер отклонит подменённый файл |
| `server` | `host` или `host:port`. Сервер добавится в «Любимые серверы» этой сборки |

## mechanica.json

Необязательный файл в корне `.mrpack` (или в `overrides/mechanica.json`). Другие лаунчеры его игнорируют.

```json
{
  "formatVersion": 1,
  "author": "Имя канала",
  "url": "https://youtube.com/@channel",
  "description": "Выживание с друзьями на 1.21.1",
  "server": {
    "name": "SMP канала",
    "address": "play.example.com:25565",
    "syncUrl": "https://play.example.com/mechanica-sync.json"
  }
}
```

`server.syncUrl` — список модов для [Mechanica Server Sync](server-mod-sync.md). Автодокачку игрок включает сам в настройках сервера.

## Безопасность

- Принимаются только HTTPS-ссылки. Файл больше 4 ГБ не скачивается.
- Перед загрузкой лаунчер показывает название и источник и ждёт подтверждения. Без подтверждения ничего не скачивается.
- Сборка ставится в новую папку и не трогает существующие сборки и миры. Пути внутри `.mrpack` не могут выйти за пределы папки сборки или изменить служебные файлы лаунчера.
- Portable-версия не регистрирует `mechanica://`, чтобы не перехватывать ссылки у установленной. В ней ссылку можно вставить через «Импорт → По ссылке».
- Если события (`mechanica://event`) запрещают создавать сборки, ссылки на сборки тоже не работают.

## Включить страницу ссылок

Страница лежит в папке `web/` и публикуется через GitHub Pages workflow `Preset link page`. Один раз включи в репозитории Settings → Pages → Source: **GitHub Actions**.
